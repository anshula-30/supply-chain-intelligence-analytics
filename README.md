# Supply Chain Intelligence & Operations Analytics

An end-to-end supply chain analytics project using Python, SQL/MySQL and Power BI to analyze procurement, inventory, supplier performance, order fulfillment, delivery performance and logistics costs.

## Project Overview

The project analyzes 15,000 supply chain records and transforms raw operational data into structured analytical data, SQL-based insights and an interactive Power BI dashboard.

## Objectives

- Analyze supplier and procurement performance
- Evaluate inventory health and stock availability
- Measure order fulfillment and delivery performance
- Analyze logistics costs and delivery lead times
- Identify operational and inventory risks

## Tech Stack

- Python
- Pandas
- SQL / MySQL
- Power BI
- DAX
- Excel

## Project Architecture

Raw Dataset → Python Data Cleaning → SQL Database → Analytical SQL Queries → KPIs & Risk Analysis → Power BI Dashboard

## SQL Analysis

The project includes SQL schemas, analytical views and queries for:

- Supplier performance
- Inventory health
- Warehouse fulfillment
- Delivery SLA
- Logistics costs
- Supplier risk
- Product performance
- Operational bottlenecks

Advanced SQL concepts include JOINs, CTEs, CASE statements, subqueries, aggregations and window functions.
